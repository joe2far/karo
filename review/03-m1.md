## Honest M1 gaps / seams left for M2 (not regressions)

1. **ConfigMap projects a single agent, entrypoint expects a full team doc.**
   `agentConfigMap` writes `json.Marshal(agent)`; `entrypoint.py` calls
   `compile_flat` (expects an `AgentTeam` document). So a provisioned pod **idles**
   until the **Dispatcher (M2)** projects the full compiled team spec and sets
   `KARO_OBJECTIVE`. The store-injection-from-DSN path is real; the end-to-end
   single-agent objective on cluster is the M2 join.
2. **Dispatcher is still a scaffold** (`internal/dispatcher/dispatcher.go`) — task
   pumping / mailbox routing / scale-up-on-task is M2.
3. **Coordinator still uses `_next_runnable`, not the atomic `claim()`** — wired in
   at M2 (the `claim()` primitive + its contract test exist now). Until then,
   local and Postgres task ordering can differ under parallel pull → this is why
   Parity Checkpoint A is `xfail` (see `04-parity.md`).
4. **SDK + Anthropic real calls** are untested (need creds) — gated behind the
   stub; run with `ANTHROPIC_API_KEY` set.
5. **Helm chart** still lacks the Dispatcher Deployment and Redis/Postgres
   subcharts (M2/install polish).
